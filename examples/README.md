# TheFork Scraper API – code examples

Examples for every TheFork endpoint of the [Piloterr API](https://www.piloterr.com). Python and TypeScript examples are in the [main README](../README.md).

```bash
export PILOTERR_API_KEY="your-api-key"   # get one at https://app.piloterr.com
```

| Language | File | Run |
|---|---|---|
| cURL (Bash) | [`curl/restaurant.sh`](curl/restaurant.sh) | `bash restaurant.sh` |
| cURL (Bash) | [`curl/search.sh`](curl/search.sh) | `bash search.sh` |
| PHP | [`php/restaurant.php`](php/restaurant.php) | `php restaurant.php` |
| PHP | [`php/search.php`](php/search.php) | `php search.php` |
| C# | [`csharp/Restaurant.cs`](csharp/Restaurant.cs) | `copy to `Program.cs`, `dotnet run` |
| C# | [`csharp/Search.cs`](csharp/Search.cs) | `copy to `Program.cs`, `dotnet run` |
| Go | [`go/restaurant.go`](go/restaurant.go) | `go run restaurant.go` |
| Go | [`go/search.go`](go/search.go) | `go run search.go` |
| Java | [`java/RestaurantExample.java`](java/RestaurantExample.java) | `java RestaurantExample.java` |
| Java | [`java/SearchExample.java`](java/SearchExample.java) | `java SearchExample.java` |
| Ruby | [`ruby/restaurant.rb`](ruby/restaurant.rb) | `ruby restaurant.rb` |
| Ruby | [`ruby/search.rb`](ruby/search.rb) | `ruby search.rb` |
| Node.js | [`nodejs/restaurant.mjs`](nodejs/restaurant.mjs) | `node restaurant.mjs` |
| Node.js | [`nodejs/search.mjs`](nodejs/search.mjs) | `node search.mjs` |
